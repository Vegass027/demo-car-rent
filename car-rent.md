## 💡 УСЛОВНЫЕ ОБОЗНАЧЕНИЯ

| Элемент | Значение |
|---------|----------|
| 🟢 Зелёный статус | Машина сдана прямо сейчас |
| ⚪ Серый статус | Машина свободна |
| 🟠 Оранжевый статус | На ТО / обслуживании |
| 🔴 Красный статус | Требует внимания (ТО скоро!) |
| ▓ Тёмный квадрат | День с арендой |
| ░ Светлый квадрат | День простоя |
| ◈ Квадрат с точкой | День с расходом (ТО/прочее) |
